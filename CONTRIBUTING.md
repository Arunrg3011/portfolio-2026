# 🤝 Contributing to Arun R. G. Portfolio

Thank you for considering contributing to **Arun R. G. — Cinematic Portfolio (portfolio-2026)**!

---

## 📋 Code of Conduct

By participating in this project, you agree to maintain a respectful, welcoming, and inclusive environment for all contributors.

---

## 🚀 How to Contribute

### 1. Fork & Clone the Repository
```bash
# Fork the repository on GitHub, then clone your fork:
git clone https://github.com/Arunrg3011/portfolio-2026.git
cd portfolio-2026
```

### 2. Install Dependencies
```bash
bun install
# or: npm install
```

### 3. Create a Feature Branch
```bash
git checkout -b feature/your-feature-name
```

### 4. Set Up Local Environment
Copy `.env.example` to `.env.local` and configure your environment parameters as described in [INSTALL.md](INSTALL.md).

### 5. Make Your Changes & Test
Ensure your code builds cleanly without errors:
```bash
npm run build
```

### 6. Commit & Push
```bash
git commit -m "feat: add amazing feature"
git push origin feature/your-feature-name
```

### 7. Open a Pull Request (PR)
- Go to the original repository on GitHub and click **New Pull Request**.
- Provide a clear description of the problem solved or feature added.

---

## 🎨 Coding Guidelines

- **Styling**: Use Vanilla CSS variables (`--orange: #ff6b1a`) and Tailwind CSS v4.
- **Components**: Keep React components modular and clean inside `src/components/`.
- **Linting**: Follow standard Next.js and ESLint rules (`npm run lint`).
- **SEO & Accessibility**: Ensure interactive elements have accessible labels and descriptive alt text.

---

If you find a bug or have a suggestion, please [open an issue](https://github.com/Arunrg3011/portfolio-2026/issues).
